## 摘要
我们提出了 SubjectAnchor，一种面向多镜头叙事的主体感知记忆到视频范式，其中当前镜头通过以前序镜头中提取的显式视觉记忆为条件来生成。其目标是在保持逐镜头提示可控性的同时，保持切换间的主体身份与场景一致性。SubjectAnchor 构建于 Wan2.2-I2V-A14B 之上，包含三个关键组件：主体相关记忆构建、主体感知的时间旋转位置编码以及记忆感知注意力划分。对于每个目标镜头，该方法通过追溯每个所需主体到其历史出现位置，并检索最相关的预计算关键帧，构建一个紧凑的记忆库。这些记忆帧被编码为模型输入的显式视觉条件，而不同主体被分配到分离的负时间槽，以减少身份干扰。此外，记忆感知注意力划分在共享骨干网络内调节记忆令牌与生成内容之间的交互。该形式保留了显式视觉记忆的外观锚定，同时与脚本驱动的逐镜头生成相兼容。实验表明，与代表性的基于记忆的方法和整体式基线相比，SubjectAnchor 提高了跨镜头身份一致性，同时保持了有竞争力的视觉质量。

## Abstract
We present SubjectAnchor, a Subject-Aware Memory-to-Video paradigm for multi-shot storytelling in which the current shot is generated by conditioning on explicit visual memories extracted from previous shots. The objective is to preserve subject identity and scene consistency across cuts while retaining the controllability of shot-wise prompting. Built on Wan2.2-I2V-A14B, SubjectAnchor contains three key components: subject-related memory construction, subject-aware temporal rotary position encoding, and memory-aware attention partition. For each target shot, the method constructs a compact memory bank by tracing each required subject to its historical appearance and retrieving the most relevant precomputed keyframes. These memory frames are encoded into the model input as explicit visual conditions, while different subjects are assigned to separated negative temporal slots to reduce identity interference. In addition, memory-aware attention partition regulates the interaction between memory tokens and generated content within a shared backbone. This formulation preserves the appearance anchoring of explicit visual memory while remaining compatible with script-driven shot-by-shot generation. Experiments show that SubjectAnchor improves cross-shot identity consistency over representative memory-based and holistic baselines while maintaining competitive visual quality.

## 1. 论文的核心问题与整体含义

- **研究背景**：视频生成已从单镜头合成走向多镜头叙事（multi-shot storytelling），电影、广告等创作通常由多个切换镜头组成，需要跨镜头保持主体身份、外观、道具和场景一致性。
- **核心矛盾**：多镜头生成必须在“全局一致性”与“逐镜头可控性”之间取得平衡。
  - 用户希望通过局部提示分别控制每个镜头；
  - 但主体身份和场景属性必须跨镜头保持一致。
- **现有范式及不足**：
  - **整体式建模**（如 HoloCine）：将所有镜头联合建模为单一长序列，有利于全局规划，但计算复杂度高（约 \(O(N^2S^2)\)），模块化不足，长序列中易发生身份漂移。
  - **显式记忆的逐镜头生成**（如 StoryMem）：每个镜头以先前视觉记忆为条件，效率较高（约 \(O(NS^2)\)），但记忆通常是非结构化的 FIFO 缓冲，依赖模型隐式判断哪些历史证据与身份相关，多主体场景下容易引入冗余或干扰。
- **本论文目标**：提出 SubjectAnchor，在保持逐镜头可控性的同时，将历史视觉记忆与“当前镜头所需主体”显式绑定，实现主体感知的记忆选择、组织与注入，从而提升跨镜头身份一致性和指令遵循能力。

## 2. 论文提出的方法论

- **总体框架**：SubjectAnchor 建立在 Wan2.2-I2V-A14B 之上，将当前镜头生成条件设置为：
  - 全局故事描述 \(g\)（场景、人物外观等持久语义）；
  - 当前镜头描述 \(c_t\)（局部动作、镜头运动）；
  - 主体相关记忆集 \(M_t\)（从先前镜头检索的显式视觉记忆）。
- **三个关键组件**：

### 2.1 主体相关记忆构建（Subject-Related Memory Construction）
- 对目标镜头 \(S_t\)，解析需要出现的主体集合 \(U_t\)（依据镜头级“Include/Exclude”标注）。
- 对每个主体 \(u \in U_t\)，回溯其最早出现镜头：
  \[
  \pi_t(u) = \min\{j \mid j < t, u \in U_j\}
  \]
- 取所有最早出现镜头的去重集合 \(\Pi_t\) 作为记忆来源，而非仅取上一镜头或聚合全部历史。
- 在 \(\Pi_t\) 中根据预计算的主体中心关键帧和相似度分数，检索 top-K 帧（最大 9 帧）构成紧凑记忆库。
- **动机**：最早出现位置通常提供主体最干净的视觉锚点，减少姿态变化、遮挡和构图漂移带来的干扰。

### 2.2 主体感知时间旋转位置编码（Subject-Aware RoPE）
- 将不同主体的记忆帧分配到不同的**负时间槽**，避免多个主体记忆在旋转位置空间中混淆。
- 主体 \(u\) 的第 \(k\) 个记忆帧的时序位置：
  \[
  \tau(u,k) = -(\sigma(u)+1)G + k\Delta
  \]
  其中 \(G\) 为主体间间隔（设为 50），\(\Delta\) 为主体内部步长（设为 5）。
- 目标视频帧保留标准非负时间索引 \(0,\dots,T-1\)。
- 这样不同主体的记忆簇被显著分离，同一主体的多个记忆帧仍保持局部时间顺序，减少身份干扰。

### 2.3 记忆感知注意力划分（Memory-Aware Attention Partition）
- 联合序列包含“记忆前缀”和“目标视频段”两个语义区域。
- **自注意力**：
  - 记忆查询只关注记忆前缀：\(o_{mem}=\text{Attn}(q_{mem},k_{mem},v_{mem})\)；
  - 目标视频查询关注完整视觉序列：\(o_{vid}=\text{Attn}(q_{vid},K,V)\)。
- **交叉注意力**：
  - 记忆查询只关注全局文本条件 \(c_{global}\)；
  - 目标视频查询关注全局 + 镜头局部文本 \(C=[c_{global},c_{shot}]\)。
- 该设计使记忆令牌作为稳定的条件令牌，而目标视频令牌可以同时利用记忆证据和局部文本，且不引入额外分支。

### 2.4 训练目标
- 采用流匹配监督微调目标，只在目标视频段上计算损失：
  \[
  L=w(t)\cdot \left\| \Omega_{vid} \odot (\hat{v}_\theta(X_t,y,p_t)-v^\star) \right\|_2^2
  \]
  其中 \(\Omega_{vid}\) 为只选择目标视频位置的二值掩码。
- 训练中记忆帧经过亮度抖动、加噪、JPEG 压缩等增强，提升对不完美记忆线索的鲁棒性。

## 7. 优点

- **显式主体感知记忆**：不再依赖扁平历史缓冲，而是围绕当前镜头所需主体进行记忆选择，减少冗余和干扰。
- **结构化记忆组织**：通过 Subject-Aware RoPE 在负时间轴上分离不同主体记忆簇，有效缓解多主体身份混淆。
- **注意力分区设计**：在不引入额外分支的情况下，使记忆令牌与生成令牌、全局文本与局部文本各司其职，保持架构简洁。
- **效率优势**：保持逐镜头生成的低复杂度 \(O(NS^2)\)，避免整体式方法的二次方扩展问题。
- **数据与评测贡献**：提出层级化多镜头标注流程和带主体 include/exclude 标签的 benchmark，为后续研究提供评测基础。
- **消融充分**：对关键组件和记忆选择策略均设置了对照实验，验证了设计的有效性。
