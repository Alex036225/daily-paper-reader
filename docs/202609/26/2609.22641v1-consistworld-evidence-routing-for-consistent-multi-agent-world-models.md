## 摘要
自回归视频世界模型能够为单一观察者生成时间上连贯的视频。将其扩展到多个智能体需要在因果流式条件下，保证独立控制视角之间以及时间间隙上的一致性。我们提出 ConsistWorld，一种多智能体世界模型，可从一幅共享图像生成静态场景的相机控制视频流。我们将一致性形式化为将来自已提交的多智能体历史和并发生成的同伴视角的证据路由到正在生成的 token。姿态条件记忆检索从所有智能体中选择相关的历史观测，恢复近期上下文窗口之外的证据。可见性门控同伴共享根据估计的历史覆盖范围和当前视角重叠程度来调节当前同伴信息。二者共同决定哪些历史观测进入上下文，以及并发的同伴信息在何处发挥作用，从而支持长期回忆和协调探索。两种机制均利用相机几何，并在固定智能体数量和检索预算下维持有界的活跃上下文。在证据共享情形以及视频长度和智能体数量泛化方面的实验表明，ConsistWorld 在保持有竞争力的生成质量的同时，实现了较强的跨时间与跨智能体一致性。

## Abstract
Autoregressive video world models enable temporally coherent generation for a single observer. Extending them to multiple agents requires consistency across independently controlled views and temporal gaps under causal streaming. We present ConsistWorld, a multi-agent world model that generates camera-controlled video streams of a static scene from one shared image. We formulate consistency as routing evidence from committed multi-agent history and concurrently generated peer views to the tokens being generated. Pose Conditioned Memory Retrieval selects relevant historical observations from all agents, recovering evidence beyond the recent context window. Visibility-Gated Peer Sharing regulates current peer information according to estimated historical coverage and current-view overlap. Together, they determine which historical observations enter the context and where concurrent peer information contributes, supporting long-term recall and coordinated exploration. Both mechanisms use camera geometry and maintain a bounded active context for a fixed agent count and retrieval budget. Experiments on evidence sharing cases and video length and agent number generalizations show that ConsistWorld achieves a strong cross-time and cross-agent consistency while preserving competitive generation quality.

## 1. 论文的核心问题与整体含义

- **研究背景**：自回归视频世界模型已能在单一观察者条件下生成时间连贯的视频，但扩展到多智能体时面临新的挑战：多个独立控制的相机必须在因果流式生成中保持场景一致性，即使它们在不同时间、从不同视角观察同一区域。
- **核心问题**：如何在不依赖显式世界状态或深度信息的情况下，让多个相机控制视频流从一张共享图像出发，长期保持跨时间、跨智能体的一致性，同时避免上下文无限增长。
- **整体含义**：论文将多智能体一致性形式化为“证据路由”问题——即对每个生成 token，在已提交历史证据与并发生成的同伴视图证据之间做出选择。ConsistWorld 通过两种关键机制在有界上下文内实现长期回忆与协调探索，为因果多智能体世界模型提供了一种可扩展的解决范式。

## 2. 论文提出的方法论

### 2.1 因果多智能体生成框架

- 给定一张共享源图像 \(I_0\) 和 \(K\) 条相机轨迹，模型自回归地生成 \(K\) 条视频流。每个时间步的所有智能体当前块联合去噪，以实现同步跨智能体交互；去噪完成后即固定为“已提交历史”。
- 所有智能体共享同一骨干网络和位置索引，仅通过 Plücker 相机条件进行区分。
- 为避免上下文随 rollout 无限增长，模型只保留每个智能体的一个近期块，并通过检索有选择地恢复更早的历史观测。
- 上下文被显式拆分为：
  - **基础上下文** \(B_v^p = S \cup W_p \cup R_v^p\)：源 token、最近已提交块、检索到的长期记忆；
  - **当前噪声块** \(N_v^p\)：当前智能体自身；
  - **同伴上下文** \(P_v^p\)：其他智能体当前正在生成的噪声块。

### 2.2 姿态条件记忆检索

- 维护一个共享的已提交块档案，检索当前局部窗口之外的历史候选。
- 用每个查询块和候选块的中间帧相机姿态作为几何条件，构造规范深度下的视锥采样点。
- 定义**有向重叠分数**：统计当前视锥采样点投影到候选图像域内的比例，并双向计算后取平均；同时加入相机光轴方向相似度作为补充分数。
- 按得分排序，检索得分最高的历史块作为当前查询的额外上下文。
- 关键点：仅依赖相机几何和规范深度，**不需要估计场景深度**；是否将某个历史块纳入上下文由姿态条件决定，而块内部哪些位置被关注仍由自注意力负责。

### 2.3 可见性门控同伴共享

- 对每个查询 token，取其图像中心像素对应的世界空间射线方向 \(r_i\)。
- 对某个相机帧 \(f\)，将 \(r_i\) 旋转到该相机坐标系并投影，计算该射线是否落入该帧的视野范围，得到**方向视野覆盖分数** \(\nu(r_i,f)\)。
- 分别对基础上下文和同伴上下文中的相机帧取最大覆盖分数：
  - \(C_i\)：当前 token 被已提交历史（源帧、近期块、检索记忆）覆盖的程度；
  - \(P_i\)：当前 token 被任一同时生成的同伴视图覆盖的程度。
- 构造**同伴门控** \(G_i = (1 - C_i) P_i\)：
  - 历史已经充分覆盖时，\(C_i\) 高，门控低，抑制同伴干扰；
  - 历史覆盖不足但同伴可见时，门控高，允许同伴信息介入；
  - 两者都不满足时，门控接近 0。
- 最终注意力输出 = 无同伴注意力输出 + \(G_i\) ×（有同伴注意力输出 − 无同伴注意力输出），实现对同伴证据的连续、逐 token 调节。

### 2.4 两种机制的耦合

- 姿态条件记忆检索会改变基础上下文 \(B_v^p\)，从而改变 \(C_i\)，进而影响同伴门控 \(G_i\)。
- 检索到的历史观测为已建立内容提供锚点，使同伴影响集中在历史证据不足的区域，避免并发视图无条件覆盖已经确定的场景内容。
- 二者共同保证：已有内容可跨时间、跨智能体恢复；新探索区域可以通过同步同伴共享实现协调。

## 3. 实验设计

### 3.1 训练数据与阶段

- **第一阶段**：在 Multi-CamVideo 数据集上训练，包含 3,400 个 Unreal Engine 场景、每场景 10 个同步相机、81 帧、分辨率 240×416，组织为 5 个自回归块。先进行多智能体教师强制，再使用 self-resampling 策略暴露模型自身生成历史。
- **第二阶段**：在 1,000 个用 Infinigen 资产渲染的多相机场景上训练，每场景 8 个同步相机流、141 帧、组织为 9 个自回归块。轨迹包含跨时间、跨视角的重复观测，专门用于训练两种证据路由机制。训练时随机采样 \(K \in \{1,2,3,4\}\) 个智能体。

### 3.2 评估协议与数据集

- **MultiCamVideo held-out 场景**：用于主要一致性评估和消融，已去除条件图像中的人物。
