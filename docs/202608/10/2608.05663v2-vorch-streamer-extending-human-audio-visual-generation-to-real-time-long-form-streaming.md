## 摘要
实时长篇化身音频-视频生成需要因果、连续的合成，同时保持视听同步和视觉一致性。将预训练的双向模型适应此设置存在两个关键困境。首先，自回归地重用生成的块作为上下文会产生曝光偏差，导致错误和视觉漂移在长序列生成中累积。其次，当只有有限的局部音频-视频上下文可用时，全局语音话语并不能指示因果生成器接下来应该说话的部分。我们提出了Vorch-Streamer，一个后训练框架，解决这些挑战并实现实时长篇文本到音频-视频（T2AV）流式传输。我们构建了一个包含8万个12至21秒化身片段的合成语料库，并首先使用混合教师强制和扩散强制训练一个因果生成器。然后，我们应用长期自我强制与DMD蒸馏，使模型暴露于自身的 rollout 分布，同时保持预训练双向教师模型的质量。为了显式控制语音进程，一个外部语言模型预测离散的25Hz语音规划令牌，其连续特征条件化音频扩散分支，并将每个因果块与其应说的内容对齐。在有限的因果上下文和四步去噪下，Vorch-Streamer从文本中联合生成音频和视频，速度达到27.12 FPS，超过了24 FPS的实时播放速率，同时在长篇生成中保持了具有竞争力的音频-唇部同步和强身份保持。

## Abstract
Real-time long-form avatar audio-video generation requires causal, continuous synthesis while maintaining audiovisual synchronization and visual consistency. Adapting a pretrained bidirectional model to this setting presents two key dilemmas. First, autoregressively reusing generated blocks as context creates exposure bias, causing errors and visual drift to accumulate over long rollouts. Second, a global speech utterance does not indicates a causal generator which portion should be spoken next when only limited local audio-video context is available. We present Vorch-Streamer, a post-training framework that addresses these challenges and enables real-time long-form Text-to-Audio-Video (T2AV) streaming. We construct a synthetic corpus of 80K avatar clips spanning 12-21 seconds and first train a causal generator with mixed Teacher Forcing and Diffusion Forcing. We then apply long-horizon Self Forcing with DMD distillation, exposing the model to its own rollout distribution while preserving the quality of the pretrained bidirectional teacher. To explicitly control speech progression, an external language model predicts discrete 25-Hz speech-planning tokens, whose continuous features condition the audio diffusion branch and align each causal block with the content it should speak. With bounded causal context and four-step denoising, Vorch-Streamer jointly generates audio and video from text at 27.12 FPS, exceeding the 24-FPS real-time playback rate while maintaining competitive audio-lip synchronization and strong identity preservation over long-form generation.

### 1. 论文的核心问题与整体含义  
- **研究背景**：实时、长篇的化身音视频生成（如虚拟人直播、交互式代理）需要模型能够因果地、连续地合成视频与同步音频。现有的高性能扩散模型（如LTX2.3）大多为双向、短时离线设计，无法直接进行流式推理。  
- **核心难题**：将双向模型适配到流式场景面临两个关键困境：  
  - **曝光偏差**：自回归地复用自身生成块作为上下文，导致错误累积、视觉漂移。  
  - **文本-时序失配**：全局语音描述无法指示因果生成器在当前有限上下文下应该说出哪一部分内容，导致语音时序混乱。  
- **整体含义**：本文提出一种后训练框架，在不从头训练的情况下，将预训练的双向联合音视频扩散模型转变为因果、实时、长篇的流式生成器，并显式解决说话内容的时序对齐问题。

### 2. 方法论  
- **核心思路**：分阶段微调，解耦因果生成与长时域适配，并引入外部语言模型进行语音规划。  
- **关键步骤与技术细节**：  
  - **合成语料库构建**：利用基础双向模型 LTX2.3 生成 80K 段 12~21 秒的化身音视频，作为模型一致性的训练数据。  
  - **混合教师强迫/扩散强迫（因果化训练）**：将双流 Transformer 转为块自回归生成器，每次生成约 1 秒的同步音视频块。注意力窗口为“前3个持久块 + 最近3个块”，训练时以 10% 概率使用干净历史（Teacher Forcing），90% 概率使用带噪历史（Diffusion Forcing），优化标准流匹配损失，形成短时因果流式模型。  
  - **长时域自我强迫与 DMD 蒸馏**：学生模型从自身预测中滚出 12~21 秒的长序列，冻结的原始双向模型作为教师。使用分布匹配蒸馏（DMD），引入可训练的双向 fake-score 模型估计学生分布，通过 fake-score 与教师 real-score 之差提供梯度方向，使学生的长时生成质量接近教师。  
  - **LLM 语音规划**：使用 Fun-CosyVoice 语言模型将全局话语预测为 25Hz 的离散语音规划令牌，经嵌入表得到连续特征。该特征通过额外交叉注意力注入音频分支，并与原有文本交叉注意力的输出进行门控融合：  
    $$h_a^\ell \leftarrow h_a^\ell + \text{sigmoid}(g_\ell) \, \text{Attn}_{\text{speech}}^\ell(h_a^\ell, e_s)$$  
    此解耦设计使每个因果块明确知道自己应说的内容，且支持沉默和语音中断。  
  - **推理配置**：每个块仅需 4 步去噪，上下文窗口采用 3 个持久前缀块 + 1 个最近块，保证恒定显存。

### 6. 主要结论与发现  
- Vorch-Streamer 是唯一超过 24 FPS 实时播放速率的原生 T2AV 模型（27.12 FPS）。  
- 在近 2 分钟的长篇生成中，同步质量（Sync-C 6.62, Sync-D 8.95）和语音准确率（WER 7.92%）接近离线双向模型 LTX2.3，显著优于其他因果流式方法。  
- 长时域身份和场景保持稳定，视觉漂移极低，而其他双向或早期流式模型随时间出现严重退化。  
- LLM 语音规划模块是解决因果生成下文本时序失配的关键，将 WER 从 184% 降至 7.92%。  
- Stage 2 的因果初始化防止运动坍塌，Stage 3 的长时自我强迫在不损失过多动态性的前提下，大幅改善长期一致性和推理效率。

### 7. 优点  
- **高效的后训练范式**：无需从头预训练，将强大但双向的模型转变为实时流式模型。  
- **精准的时序对齐**：创新地引入 LLM 语音规划并与扩散分支巧妙融合，解耦了“说什么”和“何时说”，支持流式中的语音切换和沉默。  
- **深入克服曝光偏差**：混合训练策略和长视野自我强迫对齐了训练-推理分布。  
- **高吞吐低延迟**：4 步去噪，恒定显存的窗口缓存，实现超过实时播放的生成速度。  
- **实验严谨**：多维指标、长时曲线、充分的消融，明确区分了不同输入条件下的对比并给出公正结论。

### 8. 不足与局限  
- **数据依赖**：训练数据全部由 LTX2.3 合成，可能引入原始模型的偏差，且与真实世界多样性的泛化差距未知。  
- **评估长度**：实验时长约 2 分钟，未能验证极端长时（如数十分钟）下的稳定性。  
- **比较基线**：部分比较方法因显存限制只能生成 30 秒片段，长时对比仅在可行范围内进行。  
- **上下文窗口依赖**：身份保持依赖固定的持久前缀块，可能限制大幅背景转变或多人物轮换场景。  
- **系统复杂性**：需额外部署语音规划 LLM，增加整体流水线的复杂度。  
- **缺少交互式评估**：虽然声称支持语音中断，但未在真正的交互对话基准上与全双工模型（如 Wan-Streamer）对比。
