## 摘要
实时长时化身音视频生成需要因果、连续的合成，同时保持视听同步和视觉一致性。将预训练的双向模型适配到这一场景存在两个关键难题。首先，自回归地重用生成块作为上下文会造成曝光偏差，导致长时生成中错误和视觉漂移的累积。其次，当仅能获得有限的局部音视频上下文时，全局语音话语无法指示因果生成器下一部分应说什么。我们提出了 Vorch-Streamer，这是一个后训练框架，能够应对这些挑战并实现实时长时文本到音视频（T2AV）流式传输。我们构建了一个包含 8 万个化身片段的合成语料库，时长在 12 至 21 秒之间，首先使用混合教师强制和扩散强制训练因果生成器。然后，我们应用长程自强制与 DMD 蒸馏，使模型暴露于其自身的 rollout 分布，同时保留预训练双向教师模型的质量。为了显式控制语音进程，一个外部语言模型预测离散的 25 Hz 语音规划令牌，其连续特征条件化音频扩散分支，并使每个因果块与其应说的内容对齐。通过有界的因果上下文和四步去噪，Vorch-Streamer 从文本联合生成音频和视频，帧率达到 27.12 FPS，超过了 24 FPS 的实时播放速率，同时在长时生成中保持了有竞争力的音频-唇部同步和强大的身份保持。

## Abstract
Real-time long-form avatar audio--video generation requires causal, continuous synthesis while maintaining audiovisual synchronization and visual consistency. Adapting a pretrained bidirectional model to this setting presents two key dilemmas. First, autoregressively reusing generated blocks as context creates exposure bias, causing errors and visual drift to accumulate over long rollouts. Second, a global speech utterance does not indicates a causal generator which portion should be spoken next when only limited local audio--video context is available. We present \textbf{Vorch-Streamer}, a post-training framework that addresses these challenges and enables real-time long-form Text-to-Audio-Video (T2AV) streaming. We construct a synthetic corpus of 80K avatar clips spanning 12--21 seconds and first train a causal generator with mixed Teacher Forcing and Diffusion Forcing. We then apply long-horizon Self Forcing with DMD distillation, exposing the model to its own rollout distribution while preserving the quality of the pretrained bidirectional teacher. To explicitly control speech progression, an external language model predicts discrete 25-Hz speech-planning tokens, whose continuous features condition the audio diffusion branch and align each causal block with the content it should speak. With bounded causal context and four-step denoising, Vorch-Streamer jointly generates audio and video from text at 27.12 FPS, exceeding the 24-FPS real-time playback rate while maintaining competitive audio--lip synchronization and strong identity preservation over long-form generation.

### 1. 核心问题与研究动机
实时长时化身音视频生成面临两大困境：
- **曝光偏差**：自回归地将先前生成的块作为上下文输入，导致错误累积和视觉漂移。
- **语音与局部上下文错配**：全局语音文本无法指示因果生成器在当前可获得的有限局部音视频上下文中下一步应说出哪一部分内容。
因此，直接将预训练的双向音视频扩散模型运用于实时流式生成难以保持视听同步、长时一致性和语音内容准确性。

### 2. 方法论
Vorch-Streamer 是一个后训练框架，分为三个阶段将预训练的 LTX2.3 双向模型转化为因果、实时的长时流式生成器。
- **阶段一：合成化身语料库构建**  
  利用双向 LTX2.3 模型生成 8 万个 12–21 秒的化身音视频片段，为后续训练提供模型一致的监督数据。

- **阶段二：因果音视频流式训练（混合 Teacher Forcing 与 Diffusion Forcing）**  
  将音视频潜变量划分为同步块（每块约 1 秒，3 视频帧 + 25 音频令牌），块内保持双向注意力，块间使用因果注意力（含固定数量前缀块和最近 3 个块的历史窗口）。训练时采用样本级混合策略：10% 样本采用干净历史的 Teacher Forcing，90% 采用加噪历史的 Diffusion Forcing，以减小训练–推理分布差异。优化目标为标准流匹配损失。

- **阶段三：长程自强制与 DMD 蒸馏**  
  学生因果模型通过自 roll-out（块逐块生成）产生 12–21 秒的整段序列，使用有界 KV 缓存（同推理时的上下文窗口）。以冻结的原始双向 LTX2.3 作为真实评分模型，一个可训练的双向假评分模型估计学生分布，通过分布匹配蒸馏（DMD）迫使学生样本向教师分布迁移，同时优化假评分模型。这一过程使模型直接适应长程自生成历史下的误差传播，并保留教师质量。

- **LLM 语音规划器**  
  引入 Fun-CosyVoice LLM 预测 25 Hz 的离散语音规划令牌，通过查找表与可学习投影转换为连续特征。这些特征以额外的交叉注意力分支注入音频支路，并通过门控自适应融合与原始文本条件结合，为每个因果块提供精确的局部说话内容，从而解耦语音计划与音视频生成。模型支持沉默令牌、语音中断和切换。

### 6. 主要结论与发现
- Vorch-Streamer 以 27.12 FPS 实现了实时文本到音视频流式生成，超越 24 FPS 实时播放要求。
- 通过混合因果训练与长程自强制蒸馏，可靠地解决了曝光偏差引发的长程质量退化，在约两分钟生成中保持音唇同步（Sync-C 6.62, Sync-D 8.95）和强大的身份一致性（Human Identity 0.9996）。
- LLM 语音规划器有效解决了全局文本与局部因果生成的对齐问题，使 WER 降至 7.92%，显著优于其他文本条件策略（如直接使用完整话语导致 184% WER）。
- 与现有原生 T2AV 系统相比，在更长生成时间内仍维持稳定，且无需外部音频或参考首帧。

### 7. 优点
- **系统性后训练管道**：清晰地将双向模型转换为实时流式生成器，分阶段解决因果建模、分布对齐和语音对齐问题。
- **混合训练策略与长程自强制**：有效缓解曝光偏差，使模型适应自生成上下文，保持长时稳定性。
- **显式语音规划**：将内容规划与生成解耦，提高了语音准确性和对中断/切换的支持，为交互式应用打下基础。
- **高效推理**：仅需四步去噪，结合有界KV缓存，实现恒定内存占用和超越实时的生成速度。
- **评估细致**：不仅包括聚合指标，还通过时间曲线和端点分析展示了长程行为的变化，实验对比较为全面，消融实验设计合理。

### 8. 不足与局限
- **训练数据局限**：完全依赖合成语料库，可能仍未充分覆盖真实世界化身的全部多样性，泛化至极端或未见条件的能力待验证。
- **基础模型依赖**：方法绑定于 LTX2.3 架构，迁移至其他基础模型需重新进行后训练流程，且训练计算成本高（需数百 GPU 时）。
- **对比公平性**：TIA2V 参考方法因使用外部音频和首帧，与原生 T2AV 任务不完全对等，虽文中说明了这一点，但直接数值比较时仍需谨慎解读。
- **交互评估有限**：论文虽提及支持沉默、打断和语音切换，但缺乏对这些交互场景的定量评估。
- **长时间动态与语义一致性**：两分钟生成中观察到少许漂移（如 Dynamic Degree 上升但非完全一致），更长时间（如数十分钟）下的稳定性以及复杂语义场景的连贯性未验证。
- **音质与自然度**：目前评估主要关注同步和内容准确性，对生成音频的自然度、韵律等感知质量缺少主观评测。
