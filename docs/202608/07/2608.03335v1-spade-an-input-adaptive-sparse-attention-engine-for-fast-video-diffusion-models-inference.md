## 摘要
视频扩散Transformer（vDiT）能生成高质量视频，但需付出平方级别的自注意力计算代价，使得在视频令牌规模上的推理难以承受。挑战在于输入自适应的稀疏性：以可忽略的开销选择关键的Q/K/V令牌，并利用它们实现端到端的性能提升。我们提出SPADE，一个无需训练的稀疏注意力引擎，由三部分组成：(i) vDiT-SSR，一种规范，定义了3D分块候选方案，并通过Summarizer/Estimator表达式形式化动态掩码；(ii) 使用SICS和逐头策略的运行时方案生成；(iii) 一个执行器，具备低开销的索引搜索、Flash块稀疏注意力以及核分组。在Hunyuan-Video和Wan 2.1/2.2上进行文本到视频和图像到视频生成时，SPADE在保持质量的同时提高了稀疏性和速度，注意力加速2.26至3.40倍，端到端推理加速1.49至1.80倍。我们的代码开源在https://github.com/6somehow/DAC-SPADE。

## Abstract
Video diffusion transformers (vDiTs) generate high quality but pay quadratic self-attention cost, making inference prohibitive at video-token scales. The challenge is input-adaptive sparsity: selecting critical Q/K/V tokens with negligible overhead and executing them for end-to-end gains. We present SPADE, a training-free sparse-attention engine of three parts: (i) vDiT-SSR, a specification defining 3D blocking candidates and formalizing dynamic masks via Summarizer/Estimator expressions; (ii) runtime scheme generation using SICS and a head-wise policy; and (iii) an executor with low-overhead index search, flash block-sparse attention, and kernel grouping. Across Hunyuan-Video and Wan 2.1/2.2 for text-to-video and image-to-video generation, SPADE raises sparsity and speed while preserving quality, accelerating attention by 2.26x-3.40x and end-to-end inference by 1.49x-1.80x. Our code is open-sourced at https://github.com/6somehow/DAC-SPADE.

### 1. 论文的核心问题与整体含义
- 视频扩散Transformer（vDiT）因自注意力机制计算复杂度为 O(n²) ，在视频令牌规模下推理成本极高，成为实际部署的瓶颈。
- 现有稀疏注意力方法分为静态、半静态和动态三类，各自存在适应性强但开销大、或效率高但稀疏度不足等局限，难以同时实现高稀疏度、低延迟和无损质量。
- 本文目标：提出**免训练、输入自适应的高性能混合稀疏注意力引擎 SPADE**，统一并超越以往方法，在保持视频生成质量的前提下大幅加速推理。

### 2. 论文提出的方法论
SPADE 由三个核心组件构成，实现从规格定义到高效执行的协同设计。

- **vDiT‑SSR（视频 DiT 稀疏方案表示）**  
  - 一种统一的接口，支持静态、半静态和动态稀疏模式的组合。  
  - 定义分块候选方案（3D 连续块，如空间块、时间块、混合块），通过 *Summarizer Expression* 和 *Estimator Expression* 形式化动态掩码的生成，并利用策略函数输出逐头稀疏率方案。
- **方案生成（Schemes Generation）**  
  - 对每个注意力头，在线计算**块内余弦相似度和（SICS）** 作为聚合分数，评估所有候选分块方案，选择分数最高的方案。  
  - 利用在线算法将 SICS 复杂度从 O(BS²d) 降至 O(BSd)，并用 CUDA kernel 实现高效计算。  
  - 根据聚合分数和推理状态（时间步、层级、提示索引），通过预设策略函数产生每个头的稀疏率方案（本地窗口长度、内部/外部 Top‑K 或 Top‑P）。
- **逐头稀疏注意力执行（Head‑wise Sparse Attention）**  
  - 融合布局转换、摘要化、内部重要性估计为单一 CUDA kernel，减少全局数据搬运。  
  - 按相同分块方案分组注意力头，合并启动，提高计算和利用度。  
  - 引入 **Flash 块稀疏注意力**：预处理掩码为排序的 BSR 格式，使用在线 softmax 避免实例化完整注意力矩阵，并利用 Hopper 架构的 TMA 和 warp group MMA 优化流水线。  
  - 最终输出恢复为原始布局的 O。

### 6. 论文的主要结论与发现
- SPADE 在所有模型上实现了最高稀疏度（82.32%–85.21%），超越半静态与动态基线。  
- 注意力加速 **2.26×–3.44×**，端到端加速 **1.32×–1.49×**，SPADE‑Turbo 可达 **1.80×**。

- 混合稀疏设计优于单一静态或动态方案，SICS 驱动的分块选择和聚合分数引导的策略能有效提升稀疏度和质量。

### 7. 优点
- **统一表示** vDiT‑SSR 可灵活组合静态、半静态与动态方法，并为未来设计提供可扩展框架。  
- **轻量级方案生成**，SICS 在线计算开销低（仅为稀疏注意力的 8%），却带来更高稀疏度。  
- **高性能执行**，通过算子融合、头分组、Flash 块稀疏注意力和硬件感知优化，在同等稀疏度下模式搜索和计算速度显著优于现有动态内核。  
- **免训练**，即插即用，无需微调即可适配多种 vDiT 架构。  
- 代码开源，便于复现与延伸研究。

### 8. 不足与局限
- 实验仅覆盖 Hunyuan‑Video 和 Wan 系列模型，对其他闭源或结构差异较大的 vDiT（如 Sora、Veo）效果未知。  
- 策略函数依赖人工预设的预算分配，虽然有效但可能需针对不同模型调整超参数，缺乏自动学习机制。  
- SPADE‑Turbo 在高加速下保真度显著下降（如 Hunyuan‑T2V 的 SSIM 0.57），使用时需权衡加速与质量。  
- 所有实验均在单张 H800 上完成，不同 GPU 架构或大规模并行场景下的适用性未验证。  
- 未探讨内存峰值、与其他推理优化（如 KV 缓存压缩、蒸馏）的联合效果，系统层面的整体收益边界尚不明确。
