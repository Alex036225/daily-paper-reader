## 摘要
姿态驱动人体动画从单张参考图像和驱动姿态序列合成目标人物的视频。实时生成对于直播、远程呈现和虚拟化身等交互应用至关重要，然而基于扩散的系统每个片段需要数分钟到数小时，阻碍了快速响应。我们提出 LiveAnimate，据我们所知是首个将实时流式生成与十亿参数规模的稳定长时长生成相结合的动画系统，基于一个 140 亿参数的视频扩散 Transformer（DiT）。两阶段训练流程首先通过参考锚定的教师强制适应将预训练的双向 DiT 调整为块因果自回归生成器，然后通过逐块自强制蒸馏将采样预算缩减到三步。为了在长流中保持外观，我们引入姿态检索汇聚注意力（PR-Sink），这是一种有界 KV 缓存机制，结合了永久锚定首个生成块的静态汇聚槽、保存姿态检索历史块的动态汇聚槽，以及三槽滚动窗口。当姿态重现时，PR-Sink 恢复相关外观上下文，而无需保留整个序列，因此内存和每块延迟在流时长增加时保持不变。结合 Ulysses 序列并行和算子融合，这些设计在两张 NVIDIA H100 GPU 上实现了 19.63 FPS 的流式推理。在三分钟基准测试中，LiveAnimate 从最初 30 秒到最后一分钟始终保持几乎恒定的感知质量和身份一致性（IQA 4.047 对比 4.026），而先前系统要么显著退化，要么需要数小时离线计算才能完成相同的生成。这些结果在交互式全身动画的质量、延迟和时长方面确立了一个新的运行点。

## Abstract
Pose-driven human animation synthesizes a video of a target person from a single reference image and a driving pose stream. Real-time generation is essential for interactive applications such as live streaming, telepresence, and virtual avatars, yet diffusion-based systems require minutes to hours per clip, precluding responsive interaction. We present LiveAnimate, to our knowledge the first animation system to combine real-time streaming with stable long-form generation at billion scale, built on a 14B-parameter video Diffusion Transformer (DiT). A two-stage training pipeline first adapts a pretrained bidirectional DiT into a block-causal autoregressive generator through Reference-Anchored Teacher-Forcing Adaptation, and then reduces the sampling budget to three steps through Block-wise Self-Forcing Distillation. To preserve appearance over extended streams, we introduce Pose-Retrieval Sink Attention (PR-Sink), a bounded KV-cache mechanism combining a Static Sink that permanently anchors the first generated block, a Dynamic Sink that holds a pose-retrieved historical block, and a three-slot Rolling Window. When a pose recurs, PR-Sink restores the relevant appearance context without retaining the entire sequence, so memory and per-block latency remain constant regardless of stream duration. Together with Ulysses sequence parallelism and operator fusion, these designs enable 19.63\,FPS streaming inference on two NVIDIA H100 GPUs. On a three-minute benchmark, LiveAnimate maintains nearly constant perceptual quality and identity from the first 30 seconds to the final minute (IQA 4.047 vs.\ 4.026), while prior systems degrade substantially or require hours of offline computation for the same rollout. These results establish a new operating point in quality, latency, and duration for interactive full-body animation.

## 2. 方法论

### 2.1 总体框架

- 以预训练的 14B 视频 DiT（Wan2.2-Animate-14B）为基础，将双向视频扩散模型改造为**块因果自回归生成器**。
- 系统按时间块生成视频：每个块包含 3 个潜变量帧（对应 12 个 RGB 帧），每个块做 3 步去噪，然后执行 clean KV 更新，再生成下一块。

### 2.2 Stage 1：参考锚定的教师强制适应

- 将训练视频划分为时间块，块 \(b\) 去噪时只关注真实的历史干净块 \(z^{GT}_{<b}\)，而不是自己的先前预测，从而在 Stage 1 避免自回归误差进入条件上下文。
- 引入 **Ref Sink**：对参考图像潜变量在 \(t=0\) 做前向，得到参考 KV 状态，并对所有后续时间块全局可见。
- 注意力计算形式为：  
  \[
  \text{Attn}(Q_b,K,V)=\text{softmax}\left(\frac{Q_b[K_{ref};K_{<b}]^T}{\sqrt{d}}\right)[V_{ref};V_{<b}]
  \]
  使参考图像成为永久上下文锚点，类似于 LLM 中的 attention sink。
- 推理时，去噪后的块 \(\hat z_b^0\) 通过 clean KV update 写入历史缓存，保持历史状态处于干净噪声水平。

### 2.3 Stage 2：逐块自强制蒸馏

- 目标是减少采样步骤，从 Stage 1 的 50 步降到 **3 步**，同时减小训练与推理之间的暴露偏差。
- 采用两遍逐块重放，避免保存整条自回归轨迹的激活图：
  1. **Pass 1**：学生模型无梯度地完整生成一条自回归轨迹 \((\bar z_1,\dots,\bar z_N)\)，所有块都在学生自身历史下生成，但激活不保留用于反向传播。
  2. **Pass 2**：每次重放一个块位置 \(T\)，上下文来自 Pass 1 且被 stop-gradient，只有当前块 \(z^\theta_T\) 重算并保留梯度；将重算块插入原轨迹后，对完整轨迹计算 DMD 分布匹配损失 \(L_T\)。
- 通过滑动 \(T=1,\dots,N\)，所有块位置都能获得训练信号，而峰值显存保持较低，可在单个 8×80GB GPU 节点上蒸馏 14B 模型。

### 2.4 Pose-Retrieval Sink Attention（PR-Sink）

- **动机**：保留所有历史 KV 会使内存和注意力成本随时间线性增长；有界缓存虽成本恒定，但一旦块离开滚动窗口，外观证据会不可逆丢失，尤其在姿态重现时。
- **缓存结构**：
  - **Static Sink**：永久保存第一个生成块的 KV。
  - **Dynamic Sink**：保存一个由姿态检索得到的历史块 KV。
  - **Rolling Window**：三槽，存放最近两个干净块 \(t-2,t-1\) 和当前块 \(t\)。
  - **Ref Sink**：参考图像 KV，不占用上述生成历史缓存槽。
- **姿态指纹**：使用 ViTPose 提取 133 个全身关键点；身体 20 个、左右手各 21 个，排除人脸密集轮廓点；将 3 帧有序姿态拼接后做 \(\ell_2\) 归一化，得到 558 维指纹，保留短时运动结构。
- **银行更新**：记忆银行 \(B\) 容量 \(M=5\)，存储指纹和未旋转的 KV。写满后，只有当新块能降低平均两两余弦相似度时才替换，从而保持多样性；更新限制在前 20 个块。
- **检索**：生成新块前，用当前姿态指纹与银行中除 \(b-1\) 以外的条目做最大余弦相似度检索，将命中条目复制到 Dynamic Sink。
- **位置一致性**：缓存 \(K_{raw}\) 和 \(V\)，在注意力时根据当前缓存布局重新施加 RoPE，避免历史块因时间位置变化而错位。

### 2.5 系统优化

- **Ulysses 序列并行**：每 GPU 计算局部 token 的 Q/K/V 投影，通过 all-to-all 转为按头并行布局，各 GPU 计算完整序列注意力，再反向 all-to-all 汇集；FFN 保持本地并行，KV 缓存按头分片维护。
- **torch.compile**：所有 DiT 块使用 `max-autotune-no-cudagraphs` 编译，预编译三种分辨率桶（480×480、672×384、384×672）。

- 初始模型：Wan2.2-Animate-14B，LoRA rank 128。
- Stage 1：10,000 步，学习率 \(5\times10^{-5}\)；Stage 2：20,000 步，生成器和 critic 学习率均为 \(1\times10^{-5}\)。

### 3.2 基准与评价

- 构建三分钟 benchmark：24 对参考图像–驱动视频。

  - 12 条来自 X-Dance，通过正放–倒放–正放扩展到三分钟，使姿态多次重现，专门测试身份一致性。

### 3.3 对比方法

- 对 SCAIL 和 UniAnimate-DiT 采用训练无关的滑动窗口去噪扩展协议，并统一使用 UniPC ODE 求解器。

- **PR-Sink 组件消融**：移除 Dynamic Sink、移除 Static Sink、移除 RoPE follow、用普通 teacher forcing 替换 DMD 蒸馏。
- **采样步数消融**：2 步、3 步、4 步。

## 6. 主要结论与发现

- LiveAnimate 在 2 张 H100 上达到 19.63 FPS 流式生成，每 12 帧块耗时约 0.611 s，内存和延迟不随流时长增长。
- 在三分钟 rollout 中，IQA 从 4.047 到 4.026 几乎不变，ASE 从 2.823 到 2.824 保持稳定，DINO-S 仅从 0.833 降到 0.818，表现出显著的长期稳定性。
- 相比之下，One-to-All 的 IQA 从 3.402 跌至 1.786，DINO-S 从 0.769 跌至 0.328；其他方法也出现闪烁、颜色漂移或背景漂移。
- SCAIL 和 UniAnimate-DiT 的 DINO-S 更高，但定性上存在帧间闪烁，且不是实时系统。
- 消融表明 Static Sink 提供全局身份锚点，Dynamic Sink 补充姿态特定外观；移除 Static Sink 会导致最终段 DINO-S 从 0.818 降到 0.693。
- 三步采样在效率和质量之间达到最佳平衡；四步提高帧级质量但增加延迟，两步削弱长期身份一致性。

## 7. 优点

- **首个实时 + 稳定长时的 14B 人体动画系统**：填补了十亿参数规模下流式生成和长时稳定性的空白。
- **两阶段训练设计可扩展**：Stage 1 将双向 DiT 改造为块因果生成器；Stage 2 通过两遍逐块重放使 14B 模型能在单节点上蒸馏，避免全轨迹反向传播。
- **PR-Sink 机制巧妙**：静态锚点 + 姿态检索动态缓存 + 滚动窗口的组合，用固定缓存实现长期外观一致性；姿态指纹和多样性优先银行更新进一步保证检索
